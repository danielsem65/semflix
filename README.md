## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/yourusername/semflix.git
```

Go into the project folder:

```bash
cd semflix
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
